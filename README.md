# LeoAgent — paper-трейдинг агент для MOEX

Агент торгует виртуальным капиталом 1 млн ₽ на 25 ликвидных акциях Мосбиржи:
сделки в лонг и шорт длительностью до суток по прогнозу ML-модели (LightGBM)
на часовых свечах.
Работает на VPS, о сделках пишет в Telegram, ход торгов виден в веб-дашборде.
Реальных денег и брокера нет — это стенд для разработки и проверки стратегий.

## Структура

| Путь | Что там |
|---|---|
| `app/agent/` | Торговый агент: анализ рынка, риск-менеджмент, портфель, журнал в SQLite, «уроки» по закрытым сделкам |
| `app/` | Десктоп-приложение на PyQt5: графики, ML-прогноз, чат с локальной LLM |
| `server/` | Серверная часть: планировщик, Telegram-бот, сбор цен и новостей, дашборд |
| `server/deploy/` | Установка на VPS: `install.sh`, systemd-сервисы, [инструкция](server/deploy/README.md) |
| `backtest.py` | Бэктест стратегий на истории MOEX |
| `research/` | Исследования: ML-прогноз цены, оценка методов анализа новостей, обучение модели |
| `dashboard.bat` | Открыть дашборд на ПК через SSH-туннель до сервера |

## Бэктест

Нужен Python 3.12+.

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements_server.txt
.venv\Scripts\python backtest.py --strategy agent_h1
```

История качается с MOEX ISS и кэшируется в `data/history/`. Прогон текущей
стратегии на часовых свечах по 25 бумагам — 30–40 минут на 3–4 ядрах.
Остальные режимы — в `python backtest.py --help`.

Правила подбираются на 2023–2024 годах, а проверяются на 2025–2026, которые
при подборе не используются. Результат сравнивается со случайным входом на тех
же правилах выхода, с индексом IMOEX и с фондом денежного рынка LQDT.

## Что показали бэктесты

В ячейках: доля прибыльных сделок · profit factor (прибыль ÷ убытки) · итог за период.

| Стратегия | 2023–2024 (подбор) | 2025 — окт 2026 (проверка) |
|---|---|---|
| **Текущая: ML (LightGBM), лонг + шорт, до 24 ч** | **51,4% · 1,19 · +35%** | **50,1% · 1,18 · +34%** |
| Часовые индикаторы RSI/MACD, лонг + шорт | 44,1% · 0,87 · −34% | 43,3% · 0,80 · −52% |
| Случайный вход с теми же выходами | 43,4% · 0,81 · −57% | 43,1% · 0,80 · −57% |
| Дневная, только лонг | 51,1% · 1,23 · +18% | 44,6% · 0,86 · −11% |
| Дневная + вход только при IMOEX выше SMA100 | 53,8% · 1,48 · +26% | 47,5% · 1,18 · +6% |
| Деньги в фонде LQDT, без торговли | +30% | +29% |

ML-модель на периоде проверки данных не видела: обучение и выбор порогов — по
2023–2024. Стресс-тесты (`research/ml_validate.py`): при издержках выше на
0,03% с каждой стороны — PF 1,06; при входе на час позже — PF 1,14.

Процент прибыльных сделок сам по себе не цель: настройка «близкий тейк,
далёкий стоп» даёт 72% прибыльных сделок и −66% капитала.
